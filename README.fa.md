# google-way-out

یک تونل SOCKS5 که ترافیک شما را از طریق Google Apps Script هدایت می‌کند و با استفاده از تکنیک domain fronting، اتصالات را از زیرساخت گوگل عبور می‌دهد. سرعت بهینه نخواهد بود، اما امکان مرور آزاد در محیط‌هایی که دسترسی مستقیم مسدود است را فراهم می‌کند.

---

## نحوه کارکرد

سیستم از سه بخش تشکیل شده است:

1. **کلاینت (`client.py`)** — روی دستگاه شما اجرا می‌شود. یک پروکسی SOCKS5 روی `127.0.0.1:1080` باز می‌کند. هنگامی که مرورگر یا برنامه شما از طریق آن متصل می‌شود، کلاینت فریم‌های اتصال را دسته‌بندی کرده و به آدرس Google Apps Script شما ارسال می‌کند. اتصال از طریق TLS به یک آی‌پی ثابت گوگل (`216.239.38.120`) با SNI برابر `www.google.com` برقرار می‌شود، به این ترتیب از بیرون درخواست مانند ترافیک عادی گوگل به نظر می‌رسد. یک حلقه پولینگ هوشمند با حداقل تأخیر اجباری بین درخواست‌ها، از مصرف تمام سهمیه روزانه URL Fetch گوگل (۲۰,۰۰۰ درخواست در روز) جلوگیری می‌کند.

2. **Google Apps Script (`google-script.gs`)** — به عنوان یک رله عمل می‌کند. درخواست POST دریافت‌شده از کلاینت را پردازش می‌کند، آدرس VPS هدف و محتوای پیام را استخراج کرده و با `UrlFetchApp` به VPS شما ارسال می‌کند. پاسخ VPS را عیناً به کلاینت برمی‌گرداند.

3. **سرور (`server.py`)** — روی VPS شما اجرا می‌شود. فریم‌های تونل‌شده را از رله دریافت می‌کند، اتصال TCP واقعی به هاست‌های مورد درخواست را برقرار می‌کند و داده‌ها را از همان کانال به کلاینت برمی‌گرداند.

مسیر داده به این شکل است:

```
برنامه شما -> SOCKS5 (localhost:1080) -> client.py -> Google Apps Script -> server.py (VPS) -> اینترنت
```

## پیش‌نیازها

- یک VPS با آدرس آی‌پی عمومی
- یک حساب گوگل برای استقرار Google Apps Script
- Python نسخه ۳.۸ یا بالاتر روی دستگاه کلاینت
- نصب `aiohttp` روی VPS: `pip install aiohttp`

## راه‌اندازی

### ۱. استقرار Google Apps Script

1. به [https://script.google.com](https://script.google.com) بروید و یک پروژه جدید بسازید.
2. محتوای فایل `src/google-script.gs` را در ویرایشگر قرار دهید.
3. روی **Deploy > New deployment** کلیک کنید.
4. نوع را روی **Web app** تنظیم کنید.
5. گزینه **Execute as** را روی حساب خودتان و **Who has access** را روی **Anyone** تنظیم کنید.
6. روی **Deploy** کلیک کنید و آدرس deployment را کپی کنید. شکلی مانند این خواهد داشت:
   `https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec`

### ۲. راه‌اندازی سرور روی VPS

فایل `src/server.py` را به VPS خود کپی کنید و وابستگی را نصب کنید:

```bash
pip install aiohttp
```

سرور را اجرا کنید. به صورت پیش‌فرض روی پورت `8080` گوش می‌دهد:

```bash
python3 server.py
```

برای استفاده از پورت دیگر:

```bash
python3 server.py 9000
```

مطمئن شوید که پورت موردنظر در فایروال شما باز است. سرور یک endpoint در اختیار می‌گذارد: `POST /tunnel`.

به صورت اختیاری می‌توانید `AUTH_TOKEN` را در `server.py` روی یک رشته مخفی تنظیم کنید تا از استفاده غیرمجاز جلوگیری شود.

### ۳. پیکربندی و اجرای کلاینت

فایل `src/client.py` را باز کنید و دو مقدار زیر را در ابتدای فایل تغییر دهید:

```python
SERVER_URL = "https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec"
VPS_URL    = "http://YOUR_VPS_IP:8080/tunnel"
```

اگر `AUTH_TOKEN` را در سرور تنظیم کرده‌اید، همان مقدار را در کلاینت نیز قرار دهید.

نیازی به نصب وابستگی اضافی برای کلاینت نیست. آن را اجرا کنید:

```bash
python3 client.py
```

### ۴. پیکربندی برنامه

مرورگر یا برنامه خود را روی پروکسی SOCKS5 در آدرس `127.0.0.1:1080` تنظیم کنید. در اکثر مرورگرها این گزینه در بخش تنظیمات شبکه یا پروکسی یافت می‌شود.

## مزایا نسبت به ابزارهای مشابه

- **پشتیبانی از اتصالات استریمینگ** — برخلاف ابزارهای رله HTTP ساده، این پیاده‌سازی اتصالات را در طول پولینگ زنده نگه می‌دارد، بنابراین چت‌بات‌ها و APIهای استریمینگ به درستی کار می‌کنند.
- **محافظت از سهمیه** — یک حداقل تأخیر اجباری بین درخواست‌ها و یک الگوریتم backoff تطبیقی مانع از مصرف سریع سهمیه ۲۰,۰۰۰ درخواست روزانه URL Fetch گوگل می‌شود. مصرف در فایل `gas_quota.json` ذخیره می‌شود.
- **نیازی به اعتماد به گواهی‌نامه نیست** — نیازی به نصب یا اعتماد به هیچ گواهی‌نامه سفارشی روی دستگاه شما نیست.
- **نیازی به دسترسی بالا نیست** — نه روی کلاینت و نه روی سرور نیازی به دسترسی `sudo`، `root` یا Administrator وجود ندارد.

## محدودیت‌ها

این راه‌اندازی سرعت یا پایداری بالایی نخواهد داشت. تأخیر ذاتاً زیاد است زیرا هر درخواست باید از زیرساخت script گوگل عبور کند. این ابزار برای مرور وب و استفاده سبک از API مناسب است، نه برای برنامه‌های با throughput بالا یا حساس به تأخیر.
